test_validation_utils.py
------------------------
Source: apps/commissioning/utils/validation_utils.py
DB required: No

  TestValidateAndParseIntParams
    - valid params return parsed int list
    - missing param → raises InvalidQueryParam (400, field set)
    - non-integer value → raises InvalidQueryParam
    - exotic int spellings (20_26, 2026.0, 2e3, non-ASCII digits) → raises
      InvalidQueryParam (same parser as a catalogued query param)
    - year out of range (1899 < 1900) → raises InvalidQueryParam
    - year range matches the query catalogue (1900 accepted)
    - week out of range high (54 > 53) → raises InvalidQueryParam
    - week out of range low (0 < 1) → raises InvalidQueryParam
    - "week" alias also validated (same range as delivery_week)
    - custom ranges override defaults
    - source="data" reads from POST body
    - source="data" missing field → raises InvalidQueryParam (400, field set)
    - source="data" non-object (array) body → the same missing-parameter 400,
      not an AttributeError
    - param without range passes any int
    - boundary values (2000/1 and 2100/53) accepted

  TestValidateOptionalIntParams
    - all present → parsed dict
    - all missing → dict with None values
    - partial present
    - invalid value → raises InvalidQueryParam

  TestValidateYearWeekDay
    - valid year/week/day → (int, int, int) tuple
    - missing day_number → raises InvalidQueryParam

  TestValidateYearWithOptionalWeekDay
    - year only → dict with None week/day
    - all params → full dict
    - missing year → raises InvalidQueryParam

  TestValidateBulkDocumentRequest
    - valid delivery_note request
    - valid invoice with date (parsed to a date, not passed through as a string)
    - empty ids → raises RequiredFieldMissing
    - ids not a list → raises RequiredFieldMissing
    - invalid model name → raises CommissioningError (bulk_documents.model_invalid)
    - missing ids → raises RequiredFieldMissing
    - malformed date → raises CommissioningError (bulk_documents.date_format)
    - wrong-typed date → raises CommissioningError on field "date"
    - empty / absent date still means "derive it" (None)

  TestParseBulkIds
    - returns the list of string ids unchanged
    - non-string or blank entry → raises BulkIdsInvalid (bulk.ids_invalid)
    - empty list → raises RequiredFieldMissing
    - caller can pass its own invalid-item error class
    - a batch exactly at MAX_BULK_IDS is accepted
    - over the cap → raises BulkIdsTooMany (bulk.ids_too_many) with
      details {limit, received}
    - caller can lower the cap via max_count
    - the cap error names the caller's own field
